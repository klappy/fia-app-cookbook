# Journal guidance

Journal entries preserve grounded observations and learning as work happens. They do not replace product requirements, decisions or the [harvest record](../harvest/PASS-CENSUS.md).

The shared [journal method and exact row schema](https://github.com/klappy/kitchen/blob/main/health-code/HYGIENE/journal.md) is authoritative. Authorized contributors should check the current method before use. The scaffold review receipt records the version observed during preparation. The link requires access; this page does not define a competing schema.

Only reviewed, heavily sanitized product learning belongs here. Omit raw transcripts, quotations, source identifiers, financial or negotiation details, contact or location information, private personnel matters and security details. Keep private provenance in the authorized evidence index and use a generic pointer publicly.

Record only observed events. Do not invent timestamps, quality scores, encoding receipts or approvals. If the required encoding tool is unavailable, follow the shared method's permitted floor and label the entry unvalidated. If the method cannot be resolved, return that gap instead of inventing a format.

Prepare entries for exact-text review under [AGENTS.md](../AGENTS.md) before a public write. No journal entries are created by this scaffold.
