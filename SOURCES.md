# Sources and access

Source evidence is reviewed through an [access-controlled evidence index](https://github.com/klappy/kitchen/blob/main/rail/meals/2026-09-10-fia-app-cookbook/BEE-CENSUS.json). It is available only to authorized repository readers; a public reader may see an access error.

Original material remains in its authorized source home. The private index records provenance and retrieval state so a reviewer can resolve the evidence without copying it into this public cookbook. Access to this cookbook does not grant access to those sources.

If you cannot resolve a pointer, record an access gap through the authorized coordination path. Do not reconstruct the source, request a public copy or treat an inaccessible source as reviewed.

This scaffold contains no source-derived product claims. Future public entries should use reviewed generic wording and point here for evidence access, without exposing transcript-level metadata. See the [harvest procedure](harvest/PROCEDURE.md).
